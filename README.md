# 方大同 · 1983 — 2025

一个非营利的个人纪念页。

## 内容

- `index.html` —— 站点本体。**单文件、零外部依赖**：样式与脚本全部内联，
  不引任何 CDN、外部字体或图片，离线可看、打开即用。
- `legacy/index-v1.html` —— 上一版的存档，方便随时对照或回退。

## 页面结构

| 分区 | 内容 |
|---|---|
| 封面 | 姓名、生卒、一句引言 |
| 序 | 写在前面 |
| 生平 | 分四个时期的时间轴，从 1983 年出生到 2026 年《才二十三》MV 上线 |
| 作品 | 十张录音室专辑 + 常被点起的歌 |
| 听 · 看 | 8 支 B 站现场视频（点击封面才加载播放器）+ 正版平台收听入口 |
| 荣誉 | 主要奖项 |
| 摘句 | 歌词摘句 |
| 尾声 | 收束 |

## 关于「听 · 看」这一节

- **不存储、不搬运任何影音文件**。视频始终托管在 B 站，通过其官方播放器
  (`player.bilibili.com`) 嵌入，播放计入原上传者。
- 卡片上的封面来自 B 站图床。B 站图床**对带 Referer 的请求返回 403**，
  所以每个 `<img>` 都必须带 `referrerpolicy="no-referrer"`，否则全是裂图。
- 采用**点击才加载**：进入页面不会拉取任何 iframe，点封面才注入播放器。
- 所有视频均为 B 站第三方上传，版权归方大同、赋音乐及相关权利人所有。
  若视频被下架，对应卡片会无法播放，属正常情况。
- 想听录音室版本，请走页面上的正版平台入口（网易云音乐 / QQ 音乐 / Apple Music）。

## 技术说明

- 纯静态：把 `index.html` 放到任何地方都能跑，直接双击本地文件也可以。
- 渐进增强：**默认状态下所有内容可见**，只有 JS 正常运行时才启用入场淡入动画；
  另外带一个 2.5 秒兜底定时器，确保内容永远不会被永久隐藏。
- 响应式：`560px` / `640px` / `760px` 三档断点。
- 无障碍：尊重 `prefers-reduced-motion`，支持打印样式。
